# web

Laboratorio personale per progetti legati al mondo web/internet.

## Sottoprogetti

- `laravel-lab/` — laboratorio didattico Laravel seguito lezione per lezione.

## Come usare questo repository

Questo repository è organizzato come contenitore di laboratori.

Ogni sottoprogetto ha la sua cartella e, quando serve, il suo README dedicato.

Per iniziare con Laravel, leggi:

- `laravel-lab/README.md`
- `laravel-lab/GLOSSARY.md`
- `laravel-lab/lessons/lesson-01/lesson-learned.md`
